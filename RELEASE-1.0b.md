# RingOut 1.0b

Public release target for title ID PPSA99875. The launcher name is RingOut. The owner reported that the opening movie played, Arcade character selection worked and Link, Spawn and Heihachi were usable on the private installation. The owner also saw apparent HD texture changes. A complete match on a public package and USB slots beyond USB0 remain unverified.

The existing PS5 executable contains disc-derived game code. The player's data-preparation tools reproduce the game files from owned inputs. The current Desktop backup also contains original game data, optional textures and personal saves. A public downloadable artifact has not been qualified.

The tester reported that Edge Master mode could not load fights on the build they played. The exact build and mission are unconfirmed. The latest archived startup log ends after the settings menu closes and does not identify a fight-loading failure.
