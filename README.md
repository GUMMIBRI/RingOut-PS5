# RingOut PS5 source changes

Source-only contribution against [jackpoison-prog/RingOut](https://github.com/jackpoison-prog/RingOut), commit `9339899231d9cf90282c7b4c17eb1cf0c3c4e14c`. `tracked-changes.patch` contains changes to baseline files; the `ModernGekko` and `tools` directories contain newly added source files. Apply the patch and copy these files into a separately obtained checkout at the pinned commit. The patch was checked against the baseline Git index. The public baseline's own distribution contents and licenses remain its maintainers' responsibility; it is not embedded or republished here.

The runtime derives from Dolphin and ModernGekko (GPL-2.0-or-later); the upstream RingOut project is GPL-2.0-or-later. The baseline project also uses DolRecomp (GPL-3.0-or-later) as a separate tool. The upstream RingOut, ModernGekko, and Dolphin license texts are retained in `LICENSE` and `licenses/`. The roster tools retain their GPL-3.0-or-later notice and license in `tools/roster/`. See the baseline README for its full component credits and licensing.

No game data, translated guest code, DSP ROMs, fonts, compiled binaries, or original image includes are included. `ModernGekko/ps5/build-native.py` records the existing Windows PS5 native recipe and depends on local PS5 SDK/toolchain, pre-existing host build metadata, dependency archives, and a locally generated guest module; it is not a portable one-command build. Never redistribute generated game code or private inputs. Paths in that recipe are historical local configuration and need adaptation. This is a source snapshot, not a complete build or a tested release.
