# RingOut 1.0 Beta for PS5

An unofficial homebrew port of the US GameCube version of Soulcalibur II. This is an early beta for offline play.

- Cold boot, controller input, the in-game settings menu, a completed Weapon Master fight with sound, and Arcade combat were observed on the matching PS5 executable.
- Compatibility across firmware versions, every mode and every optional texture pack is still being tested.
- Your own US GameCube disc image is required. The PS5 ZIP uses the exact executable tested on USB0 and the Windows Setup Kit creates private game files and a separate player module. Optional Xbox and PS2 discs are only needed on your PC during character import.

Read [SETUP.md](SETUP.md) for the file locations and PC preparation steps. See [SOURCE-NOTICES.md](SOURCE-NOTICES.md) for licenses and matching source.
